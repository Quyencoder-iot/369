# Hướng Dẫn Sway Nested và Plasma

Tài liệu toàn diện về Sway nested và Plasma Desktop, bao gồm cài đặt, cấu hình, và hiểu sâu về kiến trúc.

## Tài Liệu

- **[Hướng Dẫn Toàn Diện](HUONG_DAN_SWAY_NESTED_PLASMA.md)**: Tài liệu chi tiết về Sway nested và Plasma
- **[Hướng Dẫn Nhanh](QUICK_START.md)**: Bắt đầu trong 5 phút

## Scripts

- `scripts/sway-nested.sh`: Launcher cho Sway nested
- `scripts/install-sway-nested.sh`: Script cài đặt tự động
- `scripts/check-wayland-support.sh`: Kiểm tra hỗ trợ Wayland

## Ví Dụ

- `examples/sway-config-advanced.md`: Cấu hình Sway nâng cao
- `examples/layer-shell-example.cpp`: Ví dụ ứng dụng Layer Shell
- `examples/plasma-integration.md`: Hướng dẫn tích hợp với Plasma

## Bắt Đầu

```bash
# Cài đặt
./scripts/install-sway-nested.sh

# Kiểm tra hệ thống
./scripts/check-wayland-support.sh

# Chạy Sway nested
./scripts/sway-nested.sh
```
